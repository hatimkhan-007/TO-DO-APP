# 📝 Flutter To-Do App

A modern and simple To-Do application built with Flutter that helps users manage their daily tasks efficiently. This project is created for learning Flutter development, state management, local storage, and clean project architecture.

---

## ✨ Features

* ✅ Add new tasks
* ✅ Mark tasks as completed
* ✅ Delete tasks
* ✅ Beautiful and responsive UI
* 🌙 Dark mode support *(Coming Soon)*
* 🔍 Search tasks *(Coming Soon)*
* 📅 Due dates and categories *(Coming Soon)*
* 🔔 Local notifications *(Coming Soon)*
* ☁️ Firebase synchronization *(Coming Soon)*

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/hatimkhan-007/TO-DO-APP.git
```

### Navigate to Project Directory

```bash
cd TO-DO-APP
```

### Install Dependencies

```bash
flutter pub get
```

### Run the Application

```bash
flutter run
```
